# 오닐 터미널 — 모바일 앱 v2

## 지금 화면이 이상했던 이유

스크린샷의 **"샘플 데이터"** 표시가 원인입니다.
**GitHub Actions를 아직 한 번도 실행하지 않으셔서** 제가 넣어둔 샘플만 보이고 있었습니다.
그 샘플에는 미국 지수와 TEST 종목만 있어서 한국 지수가 비었고, WT를 추가해도 반응이 없던 것입니다.

**지금 바로 하실 일** — 저장소 → **Actions** 탭 → 왼쪽 **데이터 갱신** →
오른쪽 **Run workflow** 버튼 클릭. 2~3분 뒤 앱을 새로고침하면 실제 데이터로 바뀝니다.

> Actions가 실패하면: Settings → Actions → General → Workflow permissions를
> **Read and write** 로 바꿔주세요.

## v2에서 바뀐 것

### 1. 종목 입력란 추가

홈과 종목 탭 위에 **검색창**이 생겼습니다. 코드를 넣고 조회하면

- 이미 분석된 종목 → 바로 상세 화면
- 없는 종목 → 관심종목에 추가하고 저장소 갱신 안내

### 2. GitHub 연동 — 앱에서 추가하면 자동 분석

이게 가장 큰 변화입니다. 이전에는 앱에서 종목을 추가해도 **휴대폰에만 저장**되고
서버 분석에는 반영되지 않았습니다. 그래서 WT를 넣어도 아무 반응이 없었습니다.

이제 **설정 → GitHub 연동**에 아이디·저장소·토큰을 한 번만 넣으면,
앱에서 종목을 추가할 때 `data/watchlist.json`이 자동으로 갱신되고
Actions가 실행되어 **2~3분 뒤 분석 결과**가 나옵니다.

**토큰 만드는 법** (앱 안에도 안내되어 있습니다)

1. github.com → 프로필 → **Settings** → 맨 아래 **Developer settings**
2. **Personal access tokens** → **Fine-grained tokens** → Generate new token
3. Repository access → **Only select repositories** → 이 저장소 선택
4. Permissions → Repository permissions → **Contents** 를 **Read and write**
5. Generate token → 나온 문자열을 앱에 붙여넣기

토큰은 휴대폰에만 저장되며 외부로 전송되지 않습니다.
연동하지 않으면 기존처럼 "목록 JSON 복사" 후 수동으로 붙여넣으셔도 됩니다.

### 3. 한국 지수 수집 경로 보강

`KS11`/`KQ11`을 FinanceDataReader로 먼저 시도하고, 실패하면 yfinance의
`^KS11`/`^KQ11`로 넘어갑니다. 실패 사유는 설정 탭의 **데이터 수집 로그**에 남습니다.

## 설치 (처음이라면)

1. 이 폴더 **안의** 파일들을 저장소 최상위에 올립니다
   (`index.html`, `sw.js`, `manifest.webmanifest`, 아이콘 2개,
   `scripts/build_data.py`, `data/watchlist.json`, `data/summary.json`,
   `.github/workflows/update.yml`)
2. Settings → Pages → Branch `main` / `(root)` → Save
3. Actions → 데이터 갱신 → Run workflow
4. 발급된 주소를 Safari(iPhone) / Chrome(Android)로 열고 "홈 화면에 추가"

## 검증 상태

이 개발 환경은 외부 금융 사이트 접속이 차단되어 **실제 시세로는 검증하지 못했습니다.**
대신 다음을 확인했습니다.

- 분석 엔진 전체를 합성 데이터로 실행 — FTD 탐지, Market Pulse 노출도,
  공포탐욕 5개 구성요소, 베이스·피봇·해부, 고점/바닥 신호, 80% 신뢰구간, 체크리스트
- 앱 JavaScript 문법 검사 통과, onclick 참조 무결성 확인, 뷰/탭 매핑 일치
- 빌더가 만든 JSON을 앱이 기대하는 스키마와 대조 — 모든 필드 일치 확인
- 샘플 데이터에 미국·한국 시장, 환율, 공포탐욕지수를 모두 포함시켜
  Actions 실행 전에도 화면 구성을 미리 볼 수 있게 했습니다
